# InsightPress

## Project Goals
InsightPress aims to simplify business data reporting. The project plans to automate chart generation, provide natural language explanations, and offer basic forecasting so that a single command can produce a PDF report.

## Installation
### Using pip
```bash
python -m pip install -r requirements.txt
```
### Using Docker
```bash
docker build -t insightpress .
docker run --rm insightpress <cli arguments>
```

## Basic CLI Usage
Once installed, run the command-line interface with a CSV file and target output path:
```bash
python -m insight.cli data.csv --out report.pdf
```

## Narratives and Forecasting
The pipeline chooses charts based on your data and displays them with
accompanying text generated by `insight_writer`. Forecasts are produced via
simple statistical models in `forecaster` to project future trends. Narratives
and charts appear together in the final PDF report.
